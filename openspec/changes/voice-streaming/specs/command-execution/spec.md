# Spec Delta

## Purpose

规定命令进入执行队列之后怎样执行：按顺序一次一条，可以被"停"清空，并且每条命令都有统一、可追溯的结果，不管它来自快速通道还是 LLM。

## ADDED Requirements

### Requirement: 按入队顺序逐条执行
系统 SHALL 按命令进入队列的顺序逐条执行，同一时刻最多只有一条运动命令在执行。

#### Scenario: 两个来源先后入队
- **WHEN** 快速通道先放入 `forward 30`，LLM 随后放入 `left 90`
- **THEN** 先执行 `forward 30`，完成后再执行 `left 90`

### Requirement: 停止时清空队列
触发停止时，系统 SHALL 清空所有还没发出的命令，再发出 `stop`。

#### Scenario: 队列里还有命令
- **WHEN** 队列里还有 2 条没发出的命令时触发停止
- **THEN** 这 2 条不会再发出，结果里标为"被停止取消"

### Requirement: 每条命令都有结果记录
每条命令 SHALL 有且只有一个结果状态：已执行、被拒绝（附原因）、被停止取消、因通信失败跳过。一句话处理完后，系统 SHALL 输出这句话所有命令的结果汇总。

#### Scenario: 混合结果
- **WHEN** 一句话产生 3 条命令，第 1 条执行成功，第 2 条参数超范围，第 3 条被停止取消
- **THEN** 汇总里依次显示：已执行、被拒绝（参数超范围）、被停止取消
