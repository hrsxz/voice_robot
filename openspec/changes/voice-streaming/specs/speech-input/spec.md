# Spec Delta

## Purpose

规定系统怎样从麦克风得到用户说的话：用什么方式采集，怎样边说边识别，一句话什么时候算结束，识别失败时怎样回退，以及录音保留多久。

## ADDED Requirements

### Requirement: 按住空格时流式识别
在按空格模式下，系统 SHALL 在按住空格期间持续把音频送去识别，并且在说话过程中就陆续给出已经确定的分句，而不是等松开空格后才开始识别。

#### Scenario: 说话中途得到分句
- **WHEN** 用户按住空格说"前进30厘米，然后左转90度"，两个分句之间有短暂停顿
- **THEN** 在松开空格之前，系统已经给出确定的分句"前进30厘米"

### Requirement: 松开空格后很快给出整句结果
松开空格表示这句话说完了，系统 SHALL 在松开后尽快给出这句话最后一部分的识别结果，目标是不超过 0.5 秒。

#### Scenario: 松开空格
- **WHEN** 用户说完后松开空格
- **THEN** 系统在约 0.5 秒内给出这句话最后一个分句的文字

### Requirement: 流式识别失败时回退到整句识别
流式识别连不上或中途断开时，系统 SHALL 自动改用整句识别（录完再识别），并在终端提示当前处于回退模式，这条命令照常识别和执行。

#### Scenario: 流式服务不可用
- **WHEN** 流式识别服务连接失败
- **THEN** 这条命令改用整句识别后照常执行，终端提示"已回退到整句识别"

### Requirement: 临时录音用完即删
为识别而产生的临时录音 SHALL 在这条命令处理完后删除，系统 MUST NOT 长期保存用户的录音。

#### Scenario: 命令处理完毕
- **WHEN** 一条命令识别并执行完毕（无论成功还是失败）
- **THEN** 这条命令产生的临时录音文件已经删除
