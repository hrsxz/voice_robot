# Spec Delta

## ADDED Requirements

### Requirement: 流式模式下按分句路由
流式识别时，每个分句一确定，系统 SHALL 立即用本地匹配器判断：命中就按顺序放进执行队列。遇到第一个没命中的分句时，系统 SHALL 把从这个分句开始的剩余内容（直到这句话说完）交给 LLM，并告诉 LLM 前面已经执行过哪些动作。

#### Scenario: 前半句命中，后半句交给 LLM
- **WHEN** 在流式模式下说"前进30厘米，然后跳个舞"
- **THEN** `forward 30` 在 LLM 返回之前就开始执行；LLM 收到的内容是"然后跳个舞"，并附带"已执行：forward 30"

#### Scenario: 全部命中
- **WHEN** 在流式模式下说"左转90度，然后前进20厘米"
- **THEN** 两个动作都由快速通道依次执行，没有调用 LLM

### Requirement: 流式模式下听到停止词立即停止
流式识别的中间结果里一旦出现停止词，系统 SHALL 立即发出 `stop` 并清空执行队列，不等这个分句确定；这句话剩下的内容 SHALL 被丢弃。

#### Scenario: 执行中喊停
- **WHEN** 小车正在执行 `forward 100`，队列里还有 `left 90`，用户说"停"
- **THEN** 系统在这个分句确定之前就发出 `stop`，`left 90` 被取消

### Requirement: LLM 流式输出逐条执行
LLM SHALL 以每行一个动作的格式流式输出。每收到完整的一行，系统 SHALL 立即校验，合法的马上放进执行队列，不等 LLM 全部输出完；不合法的一行被拒绝并记录原因，后面合法的行照常处理。

#### Scenario: 多个动作
- **WHEN** LLM 为一句话输出 3 行动作
- **THEN** 第 1 个动作在第 3 行到达之前就已经开始执行

#### Scenario: 中间有一行不合法
- **WHEN** LLM 输出的第 2 行参数超出范围
- **THEN** 第 2 行被拒绝并记录原因，第 1、3 行照常执行
