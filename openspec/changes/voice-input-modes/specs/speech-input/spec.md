# Spec Delta

## ADDED Requirements

### Requirement: 启动时选择输入方式和语音链路
系统 SHALL 支持在启动时选择输入方式（按空格 `ptt`、唤醒词 `wake`、键盘 `cli`）和语音链路（`stream`、`realtime`）。对于不支持或暂时不可用的组合，系统 SHALL 在启动时给出明确提示并退出，MUST NOT 带着错误配置继续运行。

#### Scenario: 合法组合
- **WHEN** 以 `ptt` + `stream` 启动
- **THEN** 系统进入按空格流式识别模式

#### Scenario: 无意义的组合
- **WHEN** 以 `cli` + `realtime` 启动
- **THEN** 系统提示"键盘输入不能使用 realtime 链路"并退出

#### Scenario: 链路当前不可用
- **WHEN** 所选链路当前不可用（例如尚未实现，或缺少它需要的 API 密钥）
- **THEN** 系统提示具体原因并退出

### Requirement: 唤醒前在本地检测，不上传音频
在唤醒词模式下，检测到唤醒词之前，系统 MUST NOT 把任何音频发送到云端服务；唤醒词检测 SHALL 完全在本机完成。

#### Scenario: 背景聊天
- **WHEN** 处于未唤醒状态，屋里有人聊天，但没有人说唤醒词
- **THEN** 没有任何音频被上传，日志中没有上传记录

### Requirement: 唤醒后连续对话
检测到唤醒词后，系统 SHALL 进入连续对话窗口：窗口内说命令不需要再说唤醒词；每执行一条命令窗口重新计时，20 秒内没有命令就退出窗口；说"结束对话 / 休眠 / 再见"SHALL 立即退出窗口。

#### Scenario: 窗口内连续命令
- **WHEN** 唤醒后说"前进30厘米"，10 秒后又说"左转90度"
- **THEN** 两条命令都被执行，第二条不需要再说唤醒词

#### Scenario: 窗口超时
- **WHEN** 唤醒后 20 秒内没有说任何命令
- **THEN** 系统退出连续对话窗口，之后需要重新唤醒

### Requirement: 唤醒词后可以紧接命令
用户在同一句话里先说唤醒词再说命令时，系统 SHALL 去掉唤醒词，把后面的部分当作命令执行。

#### Scenario: 一口气说完
- **WHEN** 未唤醒时说"小蓝小蓝，前进30厘米"
- **THEN** 系统被唤醒，并执行 `forward 30`

### Requirement: 未唤醒时也能急停
即使没有唤醒，系统 SHALL 在本地识别出"停止 / 急停"并立即触发停止。

#### Scenario: 未唤醒时喊急停
- **WHEN** 小车正在运动、系统处于未唤醒状态，有人喊"急停"
- **THEN** 系统立即触发停止，不需要先唤醒

### Requirement: 句末静音时长可配置
在唤醒词模式下（没有按键标记一句话结束），系统 SHALL 根据静音判断一句话结束；静音时长 SHALL 可以配置，默认 0.7 秒。

#### Scenario: 默认静音时长
- **WHEN** 用户说完一句话后停顿 0.7 秒
- **THEN** 这句话结束并开始处理

### Requirement: 提示音不阻塞处理
播放提示音 MUST NOT 推迟识别和命令处理的开始，提示音本身也 MUST NOT 被当成用户的话。

#### Scenario: 结束提示音
- **WHEN** 一句话结束、系统播放结束提示音
- **THEN** 识别处理同时开始，耗时记录中没有因提示音产生的等待

#### Scenario: 提示音不触发录音
- **WHEN** 系统播放唤醒成功的提示音
- **THEN** 提示音不会被当成一句新的话去识别
