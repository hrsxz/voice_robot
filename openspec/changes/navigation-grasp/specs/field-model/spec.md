# Spec Delta

## ADDED Requirements

### Requirement: 物体的接近方向和目标的进入点
场地模型 SHALL 为靠墙或位置受限的命名位置点指定接近方向（小车必须从哪个方向接近），并为每个目标区域和圆圈指定至少一个进入点（位于道路网上，或者能从道路网直线到达）。物体放在没有指定接近方向的地方（任意坐标）时，系统 SHALL 自动选择一个可行的接近方向：预抓取位置和接近过程中车身不越出场地、不进入启用的禁行区、不碰到其他物体。加载时，系统 SHALL 校验每个目标都有进入点、每个指定的接近方向都是可行的。

#### Scenario: 靠墙的包裹
- **WHEN** 查询 2 号位包裹的接近方向
- **THEN** 方向是从场地内侧沿支线朝墙的方向，而不是从墙那一侧

#### Scenario: 任意摆放的物体
- **WHEN** 物体被放在场地中间一个没有命名的位置
- **THEN** 系统自动给出一个可行的接近方向

#### Scenario: 无法接近
- **WHEN** 物体被放在四周都没有足够空间的地方（例如墙角，或被其他物体围住）
- **THEN** 系统报告"物体 xxx 无法接近"，不发出任何移动

#### Scenario: 目标缺少进入点
- **WHEN** 某个目标区域没有配置进入点
- **THEN** 加载时报告"目标 xxx 缺少进入点"，并拒绝启动
