# Spec Delta

## Purpose

把感知结果、Hub 回报和任务进度汇总成一份统一的世界状态，让导航、抓取和任务层都从同一个地方读取"小车在哪、物体在哪、夹爪怎样、任务完成了多少"。

## ADDED Requirements

### Requirement: 统一的世界状态快照
系统 SHALL 提供世界状态快照，包括：小车位姿（以及是否可见、数据距今多久）、每个物体的位置和状态、夹爪状态、当前被夹住的物体。快照 SHALL 能输出成简洁的结构化摘要（坐标精确到厘米），供任务层的 LLM 使用。

#### Scenario: 查询快照
- **WHEN** 任务层请求世界状态
- **THEN** 得到包含小车位姿、全部物体、夹爪状态和被夹物体的快照，以及对应的结构化摘要

### Requirement: 物体状态
每个物体 SHALL 有且只有一个状态：在起点、被移动、被夹住、已送达、被遮挡、丢失。物体的底面和它的目标区域（或圆圈）有任何重叠时，SHALL 判定为"已送达"，和 WRO 规则"部分接触也算"保持一致。

#### Scenario: 部分接触目标
- **WHEN** 红色小人只有一部分压在 D 区的边上
- **THEN** 红色小人的状态是"已送达"

#### Scenario: 开局缺少物体
- **WHEN** 开局时没有检测到 `package_2`
- **THEN** `package_2` 的状态是"丢失"

### Requirement: 夹爪状态来自 Hub 回报
世界状态中的夹爪状态 SHALL 只来自 Hub 回报的角度；Hub 还没有回报过时，SHALL 为"未知"。

#### Scenario: 刚连接 Hub
- **WHEN** 刚连上 Hub，还没执行过任何命令
- **THEN** 夹爪状态为"未知"
