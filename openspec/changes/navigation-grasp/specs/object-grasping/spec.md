# Spec Delta

## Purpose

用笼式夹爪把物体可靠地圈进车前的笼区，并在目标位置放下；抓取后要验证有没有真的抓到，失败时自动重试，避免夹爪砸到物体。

## ADDED Requirements

### Requirement: 从预抓取点接近
抓取时，系统 SHALL 先导航到物体的预抓取点（沿物体的接近方向，在物体前方约 15 厘米处），车头对准物体，在最后的直线接近之前抬起夹爪。

#### Scenario: 抓 2 号位的包裹
- **WHEN** 对 `package_1` 执行抓取
- **THEN** 小车先到达它接近方向上的预抓取点、车头对准包裹，抬起夹爪后再直线前进

### Requirement: 物体进入笼区才放下夹爪
系统 SHALL 只在物体的估计位置落在笼区的容差范围内时才放下夹爪；否则 MUST NOT 放下夹爪，而是先后退、重新对准。

#### Scenario: 物体偏出笼区
- **WHEN** 接近完成时，物体偏出笼区 3 厘米
- **THEN** 不放下夹爪，先后退并重新对准，然后再接近

### Requirement: 抓取验证和重试
放下夹爪后，系统 SHALL 小幅后退，检查物体有没有跟着小车移动：跟着移动就标记为"被夹住"；没有跟着移动或无法判断，就抬起夹爪、后退、重试，最多 3 次，仍然失败就报告抓取失败。

#### Scenario: 抓取成功
- **WHEN** 放下夹爪后后退 3 厘米，物体随小车移动
- **THEN** 物体被标记为"被夹住"

#### Scenario: 多次失败
- **WHEN** 连续 3 次验证物体都没有随小车移动
- **THEN** 系统抬起夹爪、后退，并报告"抓取失败"

### Requirement: 放下物体
放下时，系统 SHALL 移动到笼区中心落在目标区域（多边形或圆圈）内的位置，抬起夹爪，后退至少 10 厘米，然后确认物体的状态变成"已送达"。

#### Scenario: 放到红色圆圈
- **WHEN** 夹着红色服务机器人执行放到红色圆圈
- **THEN** 物体和红色圆圈有重叠，状态变成"已送达"，小车后退离开

### Requirement: 一次只夹一个物体
正在夹着一个物体时，系统 MUST NOT 开始另一次抓取。

#### Scenario: 已经夹着物体
- **WHEN** 夹着 `yellow_person` 时请求抓取 `green_person`
- **THEN** 请求被拒绝，原因是"已经夹着 yellow_person"
