# 提案：导航 + 抓取（navigation-grasp）

## Why

有了感知（`vision-field-model`）之后，还需要一层确定性的执行逻辑，才能把"把黄色小人送到 A 区"变成一连串可靠的前进、转向和夹爪动作：知道当前世界的状态，沿黑线走到指定位置并边走边纠偏，用笼式夹爪把物体圈住、验证、再在目标位置放下。这一层不用 LLM，可以测试、可以调参。另外，摄像头还没到货，需要一个模拟器，让这部分现在就能开始开发。

## What Changes

- 新增世界状态：小车位姿、每个物体的位置和状态（在起点 / 被移动 / 被夹住 / 已送达 / 被遮挡 / 丢失）、夹爪状态，统一提供给任务层查询。
- 新增运动学模拟器：模拟小车运动（可设置误差）、物体和笼式夹爪，接口和真实的感知、Hub 完全一致。
- 新增道路网路径规划：沿黑线找最短路线；启用禁行区后自动绕开。
- 新增闭环 `go_to`：转向 → 前进一小段 → 重新测量 → 直到误差在容差以内；失败时停车并说明原因。
- 新增笼式抓取：预抓取点 → 对准 → 抬起夹爪直线接近 → 物体进入笼区才放下夹爪 → 后退验证 → 失败时自动重试。
- 新增放下：笼区中心进入目标区域 → 抬起夹爪 → 后退 → 确认物体已送达。
- 安全约束：不发出会越出场地的移动；看不到小车位姿时暂停；任何时候都可以停止。
- 场地模型增加每个物体的接近方向和每个目标的进入点。

## Capabilities

### New Capabilities

- `world-state`：把感知结果、Hub 回报和任务进度汇总成统一的世界状态。
- `navigation`：沿道路网规划路线，并闭环到达指定位置和朝向。
- `object-grasping`：笼式夹爪的抓取、验证、重试和放下。
- `motion-simulator`：在没有摄像头和小车时，模拟小车、物体和夹爪。

### Modified Capabilities

- `field-model`（由 `vision-field-model` 引入）：新增物体接近方向和目标进入点。

## Impact

- **代码**：新增 `pc/world/`（世界状态）、`pc/navigation/`（规划、控制、抓取）、`pc/sim/`（模拟器）；场地模型数据文件增加接近方向信息。
- **前置条件**：`vision-field-model`（感知和场地模型）、`hub-protocol-v2`（可打断的停止、夹爪角度回报、动作完成事件）。模拟器部分可以在摄像头到货前先做。
- **待提供的资料**：笼区内宽和内深、各物体底面尺寸（都作为配置参数）。
- **依赖**：不新增依赖。
