# 测量记录：感知 + 场地模型（vision-field-model）

## 合成数据（2026-11-13，没有摄像头）

画面由 `pc/vision/synthetic.py` 按已知参数合成，所以能和真值比较。**合成数据只能验证几何和算法**：模型完全准确、没有运动模糊、颜色理想，实际误差要看 4.3 和 6.2 的实车测量。

条件：1920×1080，水平视场角 70°，径向畸变 k1 = -0.12、k2 = 0.05；三脚架在 D 区一侧，离场地下边约 100 cm、高 175 cm，对准场地中心；画面加 σ = 2 的噪声。相机位姿由画面里检测到的 4 个 anchor 求出（不是直接用真值）。

| 项目 | 结果 | 要求 |
|---|---|---|
| 相机位姿（16 个 anchor 角点） | 重投影误差 0.24 像素，anchor 反投影误差 < 0.1 cm，相机位置误差 < 2 cm | — |
| 内参标定（20 张合成棋盘格，1280×720） | 重投影误差 < 0.5 像素，fx 误差 < 1%，画面边缘去畸变误差 < 1 像素 | 误差 > 1 像素拒绝保存 |
| 小车定位（渲染画面，7 × 4 个位置覆盖整块场地，朝向随机） | 位置误差中位数 0.09 cm、最大 0.12 cm（最远一排也是 0.12 cm）；朝向误差最大 0.5° | ≤ 2 cm、≤ 3° |
| 原地转一圈（12 个朝向，marker 偏离转弯中心 (-2, 1) cm） | 转弯中心变化 ≤ 1 cm（单元测试） | ≤ 1 cm |
| 不修正 marker 高度（当作在地面上） | 远角误差 > 5 cm 或尺寸校验失败 | 说明视差修正是必要的 |
| 物体检测（Starter 2022 布局 10 个物体 + 小车） | 10/10 检测到、颜色全对；视差修正后位置误差 ≤ 1 cm；空场地 0 个误检（D 区、四个圆圈都不会被当成物体）；小车不会被当成物体 | ≤ 2 cm |
| 同色物体在同色元素上 | 红色服务机器人在红色圆圈上：检测到，误差 < 0.2 cm；蓝色大人在蓝色 C 区里：加双阈值前 2.7 cm，加了以后 0.35 cm | ≤ 2 cm |
| 光照 | 亮度降到 50% 时警告，95% 时不警告 | 偏差 > 25% 警告 |
| 场地核对 | 合成参考图和 `wro_field.yaml` 一致；把 B 区平移 4 cm、红色圆圈平移 3 cm 时都能报告出来 | 报告 > 2 cm 的偏差 |
