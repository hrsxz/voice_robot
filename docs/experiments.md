# 待做实验清单

这里汇总所有需要连接实车、真人说话或外接硬件才能完成的验收实验。每个 OpenSpec 改动实现完后，把它的实验追加到本文末尾。

做完一项后打勾，把生成的日志文件路径或观察结果告诉 Claude，由 Claude 统计数据、写进对应改动的 `measurements.md`，并勾选 tasks.md 里的任务。

## 通用准备

- [ ] **先把新版 Hub 程序（协议 v2）下载到 Hub**：按 README 第 12 节，用 Pybricks Code 下载 `spike_hub/control_by_llm.py`。PC 连上后会先做版本握手，Hub 上还是旧程序时，PC 会提示"Hub 程序需要更新"，并拒绝发送任何运动命令，所以这一步是所有实验的前提。
- [ ] Spike Hub 已充电，每次使用前按 Hub 中间按钮启动程序
- [ ] 电脑蓝牙已打开，Hub 名称是 `Pybricks Hub`
- [ ] 项目根目录下的 `.env` 里有 `OPENAI_API_KEY`
- [ ] 两个夹爪在启动前手动放在"放下"位置（Hub 程序启动时会把这个位置当作 0°）
- [ ] 小车前方至少有 1.5 米空地，旁边有人随时可以按 Hub 按钮停车

所有设置都通过启动参数完成，不用改代码（`python -m pc.voice_to_robot --help` 查看全部参数）。`--hub ble` 表示连接真实 Hub，不加时是模拟 Hub。每个实验下面写了完整的启动命令。

**建议的实验顺序**：先做 **1c-1、1c-2**（确认 Hub 新程序本身正常，最基础），再做 1a、1b，然后做 1c-3、1c-4（语音 + 打断的集成测试），然后做 4-1 到 4-4（唤醒词模式），最后做 5-1 到 5-3（realtime 链路）。前面的实验出问题时，后面的结果也就没意义了。

| # | 说 / 输入 | 小车应该 |

| 3 | 把夹子抬起来 | 两个夹爪抬起 |

- [ ] `wake`：3 条都正确；第 2、3 条**不用再说唤醒词**（在 20 秒内说）

- [ ] 启动时第一行显示的"输入方式 / 语音链路 / Hub"和命令一致

**唤醒模式下再补充 3 项**：

- [ ] 一口气说"小蓝小蓝，前进30厘米"（中间不停顿）：小车前进 30 cm

**注意费用和数据保护**：realtime 链路按音频计费，比 stream 链路贵（README 第 8 节）；做实验时只有自己说话，旁边的人知道麦克风开着就行。整个改动 5 的实验加起来，预计 API 费用在 1 美元以内。

**和 stream 链路的区别**（做实验时注意观察）：realtime 没有本地快速通道，简单命令也要等模型，第一个动作大约 0.5–0.7 秒后才开始；多步命令是一步一步给出的，每一步约 0.45 秒，但小车在第一步时就已经开始动了。终端里每个动作显示为 `Realtime 调用: forward 30`，汇总行显示 `路由=Realtime`。

### 实验 5-1：按空格 + realtime（任务 4.2 前半）


启动时应该显示 `语音链路：realtime（gpt-realtime-mini）` 和"realtime 会话已建立（不按空格时不上传音频）"。

**步骤**：按住空格依次说下面 6 句（docs 第 1–2 级例句），每句说完等小车动作完成再说下一句：

| # | 说什么 | 小车应该 |
|---|---|---|
| 1 | 向前走 30 厘米 | 前进 30 cm |
| 2 | 向左转 90 度 | 左转 90° |
| 3 | 把夹子抬起来 | 两个夹爪抬起 |
| 4 | 向前走五十厘米，然后向右转九十度 | 前进 50 cm，再右转 90° |
| 5 | 往后退十厘米，再把夹子放下 | 后退 10 cm，再放下夹爪 |
| 6 | 左边的夹子抬起来，右边的夹子放下 | 左夹爪抬起，右夹爪放下 |

- [ ] 6 句都正确；有错的话记下句子编号、终端里的 `[realtime] 转写:` 和 `Realtime 调用:`
- [ ] 第 4–6 句：第一个动作开始后，第二个动作**不重复**、不遗漏
- [ ] 主观感觉和 stream 链路（实验 1b-1）比，反应快 / 差不多 / 慢

**运动中喊停**：说"向前走一米"，小车开始走后，**再按住空格**说"停"。

- [ ] 小车在走完一米之前停下，终端显示 `[realtime] 急停（识别到：停）`（或"模型调用 stop"）和 `被停止中断 forward 100`
- [ ] 重复 3 次，3 次都停下

**连续说两句**（观察设计里提到的风险）：说"向前走三十厘米，左转九十度，一共做四次"，小车开始动后马上再按空格说"然后把夹子抬起来"。

- [ ] 记下小车实际做了什么：正方形走完后夹爪抬起一次（正常），还是夹爪抬起了两次 / 提前抬起（把终端输出拍照或复制下来）

### 实验 5-2：唤醒词 + realtime（任务 4.2 后半）

```bash
python -m pc.voice_to_robot --hub ble --input wake --pipeline realtime --latency-log logs/latency_rt_wake.jsonl --upload-log logs/uploads_rt.jsonl
```

**步骤**：

   - [ ] 终端显示"已结束对话"，之后直接说"向左转90度"不执行
6. 再唤醒一次，然后 25 秒不说话。
   - [ ] 终端显示"连续对话已超时"；之后说命令不执行
